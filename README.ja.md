# Tickban

[English](README.md) | [日本語](README.ja.md)

ObsidianのVault全体からタスクを自動で収集し、カンバン形式で視覚化・管理するためのプラグインです。

## 動機

「Obsidianを雑に使用している場合でも、カンバンで効率的にタスク管理をしたい」という思いから作成しました。

特定のファイルにタスクをまとめる必要はありません。日報、プロジェクトノート、あるいは適当なメモ書きの中に散らばっている `[ ]` タスクを、このプラグインが自動で見つけ出し、一つのボードに集約します。

## 主な機能

- **Vault全体のタスク収集**: 指定したフォルダやファイル（Globパターン対応）から、チェックボックス付きのリストアイテムを自動で抽出します。
- **進捗状況の自動マッピング**: 以下の記法に基づいて、タスクを「TODO」「DOING」「DONE」の列に分類します。
  - `[ ]` -> **TODO**
  - `[/]` -> **DOING**
  - `[x]` -> **DONE**
- **ドラッグ＆ドロップとメニュー操作**: カンバンボード上でタスクをドラッグ＆ドロップするか、カードメニューを使用することで、ノート内のチェックボックスの状態を直接更新できます。
- **タグの抽出と表示**: タスク行に含まれる `#tag` を自動で認識し、カード上にバッジとして表示します。
- **カードメニュー**: カードをクリックするとメニューが開き、以下の操作が可能です：
  - タスクが記述されているノートの該当行へジャンプ。
  - タスクのステータス（TODO, DOING, DONE）を変更。
- **柔軟なフィルタリング**:
  - Globパターンによる収集対象の絞り込み（特定のフォルダを除外するなど）。
  - 完了済みのタスクを、ファイルの最終更新日時に基づいて自動的に非表示にする機能。

## 使い方

1. プラグインを有効にします。
2. サイドバーのリボンアイコン（カンバンアイコン）をクリックするか、コマンドパレットから `Tickban: Open kanban` を実行してボードを開きます。
3. 必要に応じて設定画面から `Include glob` や `Exclude glob` を調整し、タスクを収集する範囲を設定してください。

## 設定

- **Include glob**: タスクを収集するファイルのパターン（例: `**/*.md`）。
- **Exclude glob**: 収集から除外するファイルのパターン（例: `Templates/**`）。
- **Show file path**: カードにファイルパスを表示するかどうか。
- **Hide done tasks (days)**: 完了したタスクを何日後に非表示にするか（0で常に表示）。

## インストール方法

### 手動インストール
1. リリースページから最新の `main.js`, `manifest.json`, `styles.css` をダウンロードします。
2. Vaultの `.obsidian/plugins/obsidian-tickban` フォルダに配置します。
3. Obsidianの設定からプラグインを有効にします。
